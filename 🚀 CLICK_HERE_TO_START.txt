❓ TROUBLESHOOTING:

Problem: "localhost refused to connect"
Solution: Make sure BOTH batch files are running (2 windows open)

Problem: "Port already in use"
Solution: Close other programs or restart your computer

Problem: Tests fail
Solution: 
  1. Close both server windows
  2. Wait 5 seconds
  3. Run 1-start-backend.bat
  4. Wait for "Application startup complete"
  5. Run 2-start-frontend.bat
  6. Run 3-open-browser.bat
